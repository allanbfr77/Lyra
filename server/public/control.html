Ajuda do servidor

Resumo do papel do Servidor no Lyra e passos práticos para usar e recuperar a janela.

O que e o servidor

Servidor e o aplicativo do Lyra que roda no PC ligado aos monitores ou projetores. Ele recebe os comandos do controlador, publica o IP da maquina na rede local e envia o conteudo para as janelas de exibicao.

O que ele faz
  • Centraliza a exibicao: abre e mantem as janelas de publico, ministrante e relogio.
  • Recebe comandos: sincroniza slides, Biblia, audio e apresentacoes enviados pelo controlador.
  • Disponibiliza acesso na rede: mostra o IP desta maquina para que outros dispositivos do Lyra encontrem o servidor.
Como iniciar
  • App instalado: abra o Lyra - Servidor no PC conectado as telas e aguarde esta janela aparecer.
  • Ambiente de desenvolvimento: na pasta server, rode npm start para abrir o Electron.
  • Confirmacao rapida: verifique se o IP foi carregado e se o status aparece como Online.
Como recarregar
  • Use o botao ↻ no canto superior direito para recarregar a janela do Servidor.
  • Se a interface travar, recarregue primeiro e depois confirme se os monitores continuam reconhecidos.
Se der erro
  • IP vazio ou conexao falhando: confirme se o Servidor e o controlador estao na mesma rede local.
  • Monitores nao aparecem: confira cabos, adaptadores e use o modo estendido do Windows, nao duplicacao.
  • Janela ou exibicao parou: tente recarregar pelo botao ↻; se nao resolver, feche e abra o aplicativo novamente.
