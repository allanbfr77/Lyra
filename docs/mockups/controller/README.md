# Mockup — redesign do Controlador

Protótipo **cosmético** e clicável do painel do operador. Não liga a Electron, socket nem API.

## Como abrir

No Explorer ou no browser:

```
docs/mockups/controller/index.html
```

Ou a partir da raiz do repo:

```powershell
start docs\mockups\controller\index.html
```

## O que podes fazer aqui

- Navegar: **Home**, **Bíblia**, **Mídias**, **Slide**
- Abrir **Ajustes** (Conexão, Telão, Ministrante, Relógio)
- Alternar **tema** claro / escuro
- Simular badge **LOCAL** ↔ **SERVIDOR** (dentro de Ajustes › Conexão)
- Ligar/desligar o indicador de **Voz** (só visual)

## O que isto não é

- Não é o app real (`controller/public/controller.html` não foi alterado)
- Não projecta, não grava playlist, não fala com o Servidor
- Dados e textos são inventados

## Direção visual

Evolução da marca Lyra (carvão `#232328` + ouro `#c49a3a`): pedra fria no claro, logo carvão no escuro, ouro como acento fino — mesmas funções e dock, pele nova.
